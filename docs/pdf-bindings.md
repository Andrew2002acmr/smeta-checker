# Явная связь ВОР и ПД

На странице версии ВОР в блоке «Проверка и запуск» для каждой ссылки на файл
можно выбрать конкретную версию загруженного PDF, включая копию с другим именем.
Кнопка «Сохранить привязки ПД» фиксирует выбор для этой версии ВОР. До сохранения
запуск проверки недоступен. Пустой выбор возвращает автоматический поиск по имени.

Связи хранятся в document_versions.pdf_bindings (миграция 0008_pdf_bindings):
нормализованная ссылка из ВОР → UUID версии PDF. Проверяются проект, тип и архив.
Новая версия ВОР получает собственные привязки. Выбранная версия PDF сохраняется
при появлении новых редакций. Недоступный выбранный PDF не заменяется молча.

При запуске связи копируются в config.pdf_bindings, точные UUID закреплены
config.pdf_versions и run_pdf_versions. Предварительная проверка и PDF-обработчик
используют один resolver с приоритетом явной связи. Изменение настроек ВОР не
меняет текущие и завершённые проверки. Проверка обозначений внутри ПД сохраняется.

API: GET/PUT /api/v1/documents/{vor_version_id}/pdf-bindings. PUT принимает
{"bindings": {"original.pdf": "uuid-версии-копии"}}; пустой объект снимает связи.
Для применения требуется совместное обновление API, PDF worker и интерфейса.
