ЗАМЕТКИ ПО НОРМАТИВАМ ИЗ НЕЗАВИСИМОГО АУДИТА

1. Геометрия работы, закупочный расход материала и процент стоимости — разные
величины. Методики 421/пр и 15/пр не дают универсального запаса к метрам установки.
±10% из п.18 Методики15/пр относится к разработке норм потерь, а не допуску ВОР.
2. ГЭСН27 п.1.27.18: толстое основание нормируется по технологическим слоям.
Одна площадь в двух технологических слоях сама по себе не дублирование.
3. Коэффициент ЩПС1,26 может объясняться запасом на уплотнение. СП78 п.10.2
содержит ориентир1,25–1,3 для соответствующих материалов; нужен точный проектный
коэффициент/пробная укатка. 126 из другой нормы приложения27.2 не универсально.
4. ГЭСН27 п.1.27.35 в области перечисленных норм отдаёт приоритет проектному
расходу асфальта. Приложение27.1 — при отсутствии проектного расхода. Плотность
каменных компонентов из таблицы не равна плотности готовой смеси.
5. Приказ69/пр07.02.2025, физическаястр189 копии: п.1.27.37 задаёт порог7см
для перечисленных таблиц и исключение розлива для27-06-031. Старые8см не смешивать.
6. ГЭСН27-06-035-01:1,03т эмульсии на1т работ; не повторять ресурс поверх нормы.
Литры переводятся в массу с плотностью; уточнять расход по эмульсии/остатку битума.
7. ГЭСН47 п.1.47.3: десять поливов газона; сравнение цикла с одним поливом даёт
ложное замечание×10. Проверять включён ли уход в выбранную расценку посева.
8. Разные площади подслоёв могут следовать из откосов и уступов под бортом.
Совпадение численной реконструкции не доказывает исходные проектные контуры.
9. Типовой объём борта поГОСТ6665 не всегда описывает согласованное исполнение
поГОСТ32961; проверять паспорт. Для дублей/пропусков ресурсов нужна ЛСР.

Это заметки для разработчика проверки, не набор автоматически исполняемых правил.
Для юридически/инженерно значимого вывода сверять применимую редакцию и объект.
