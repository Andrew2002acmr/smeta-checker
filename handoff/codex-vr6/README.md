# Codex Agent и выборочный OCR для ВР-6

Патч подготовлен для версии smeta-checker с каталогами `backend/` и `frontend/`, коммит `950b48008ac7d73788562b4ffb7f85a91161b9b8` из `KDFP-IT/smeta-checker`. В этой ветке личного репозитория патч хранится как файл для просмотра и переноса. Её базовая ветка `dev` содержит версию со Streamlit.

## Что изменилось

- Добавлен экспериментальный режим Codex Agent. Он использует закреплённые версии ВОР, ПД и нормативов, локальный MCP для чтения документов, структурированное заключение и независимую серверную проверку источников и расчётов.
- Добавлены выборочное чтение числовых ячеек сканированных таблиц и раздельный кэш структуры и значений в рамках запуска. Инструмент находит пересечение подписи строки и заголовков. Для чисел сохраняет согласованные чтения RapidOCR и Tesseract и координаты в исходном PDF. Валидатор может проверять буквальные цитаты по этому кэшу.
- При таймауте основного разбора растровой таблицы добавлено ограниченное дочитывание пустых десятичных ячеек по вырезкам. Состояние частично распознанной страницы сохраняется явно.
- Linux-воркер запускает MCP через Python своего виртуального окружения. Опциональный `CODEX_AUDIT_PROXY` передаётся только процессу Codex. В Docker воркеру требуется маршрут до прокси, а доступ к PostgreSQL может оставаться через отдельную внутреннюю сеть.
- Добавлены отображение независимых выводов, телеметрия, экспорт и сравнение запусков в Nuxt.

## Как посмотреть и применить

Откройте `codex-vr6-reviewed.patch` в редакторе или используйте его в рабочей копии совместимой версии. Для проверки и применения из корня совместимого репозитория:

```powershell
git apply --check <путь-к-патчу>
git apply <путь-к-патчу>
```

Настройка воркера описана в `docs/codex-audit.md`, который входит в патч. Для локального Docker с HTTP-прокси Windows задайте `CODEX_AUDIT_PROXY=http://host.docker.internal:<порт>` в окружении воркера. Значения доступа и профиль входа задаются на каждом ПК локально.

## Что проверено

- На стр. 89 запрос объёмов переиспользовал структуру после запроса площадей. Он дочитал две ячейки за 1,8 с, повторные запросы прошли без OCR.
- В живом пилоте строк 18–21 ВР-6 локальный воркер подключился к ChatGPT через прокси, отработали три субагента, агент извлёк обе площади и оба объёма. Сервер отклонил итоговый JSON: восемь цитат короче четырёх символов, требуемых схемой. Карточки этого запуска не опубликованы.

ПД, ВОР, нормативные PDF, дампы, локальный кэш и данные входа в этот коммит не входят.
